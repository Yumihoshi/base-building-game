# EP01
定义了基本的Model类，其中LooseObject为掉落物模型类，InstalledObject为固定物品（安装物）模型类。
《环世界》中这两种类是可以互相转换的，例如对于门来说，首先可以通过材料（掉落物）在工作台制成掉落物门，然后可以将掉落物门安装在墙上，变成固定物品门。反之，也可以将固定物品门拆卸，变回掉落物门。
AI了一下，最好不要弄成两个类，而是组件思想，Entity基类包含bool（是否可安装）和一个installComponent这种。
然后是World类，对于类环世界2d游戏来说，很直观的想法是二维数组，但其实也可以用图结构（Tile类里含north south east west四个其他Tile的引用这种），虽然不一定会这样实现，但也需要考虑。
在设置World默认长宽值时，虽然可以后续游玩慢慢调整，但需要考虑到性能优化问题，地图过大时可以对摄像机外的瓦片剔除渲染/摧毁物体重新分配内存。Unity中拖慢游戏的常常是游戏物体，而非纯数据类。
实现GetTileAt方法需要权衡用懒加载还是构造函数中就初始化所有Tile。
小技巧：类默认字段是私有的，所以可以不用写private，需要更改访问权限时再写public或protected。
对于开发阶段来说，尽可能让报错明显、详细，方便debug。而发布版本则需要考虑默认值和容错处理，避免游戏崩溃。
